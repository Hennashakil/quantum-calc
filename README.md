# 🚀 QuantumCalc Deployment Guide

Your ultra-modern futuristic calculator is ready to go live! Follow these steps to deploy it to the web.

## ⚡ Option 1: Vercel (Recommended)
1.  Go to [Vercel](https://vercel.com).
2.  Click **"New Project"**.
3.  Upload the `index.html` file or connect your GitHub repository.
4.  Vercel will automatically detect the settings and deploy it.

## ⚡ Option 2: Netlify
1.  Go to [Netlify Drop](https://app.netlify.com/drop).
2.  Drag and drop the `index.html` file into the browser.
3.  Your site will be live instantly!

## ⚡ Option 3: GitHub Pages
1.  Create a new repository on GitHub.
2.  Push your code:
    ```bash
    git remote add origin <your-repo-url>
    git push -u origin master
    ```
3.  Go to **Settings > Pages** and select the `master` branch.

## 🛠 Local Development
To run the project locally with a proper web server:
1.  Open your terminal.
2.  Run: `node server.js`
3.  Visit: `http://localhost:3000`
